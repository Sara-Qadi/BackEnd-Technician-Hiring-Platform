# Technician Hiring Platform Backend

## Overview

This repository contains the Laravel REST API backend for the Technician Hiring Platform.
It powers authentication, job postings, proposals, messaging, and reporting for a separate frontend application.

## Features

- User Authentication: Login, registration, and token-based access via Laravel Sanctum.
- Job Posts: Create, update, browse, and manage job postings.
- Proposals & Submissions: Submit proposals, accept/reject submissions, and track job progress.
- Profiles & Reviews: Manage user profiles and collect ratings/feedback.
- Messaging & Notifications: Send messages and receive notifications on platform activity.
- Admin Tools & Reports: User moderation, job oversight, and reporting endpoints.

## Technologies Used

- Backend: Laravel 12 (PHP 8.2)
- Authentication: Laravel Sanctum
- Database: MySQL
- Utilities: Laravel Artisan, Maatwebsite Excel (exports)

## Installation

1. Clone the repository.
2. Install dependencies.
3. Configure the `.env` file.
4. Generate the application key.
5. Run migrations.
6. Start the local server.

```bash
git clone <REPO_URL>
cd BackEnd-Technician-Hiring-Platform
composer install
copy .env .env.backup
# update .env with your local settings
php artisan key:generate
php artisan migrate
php artisan serve
```

## Environment Variables

- `APP_ENV` – application environment (e.g., `local`, `production`).
- `APP_KEY` – application encryption key generated by `php artisan key:generate`.
- `APP_URL` – base URL for the API.
- `DB_CONNECTION` – database driver (e.g., `mysql`).
- `DB_HOST` – database host.
- `DB_PORT` – database port.
- `DB_DATABASE` – database name.
- `DB_USERNAME` – database user.
- `DB_PASSWORD` – database password.

## Authentication

This API uses Laravel Sanctum with token-based authentication.
Send the token on protected requests using the header: `Authorization: Bearer <token>`.
Routes grouped under the `auth:sanctum` middleware are protected.

## API Basics

- Base URL: `http://127.0.0.1:8000` (when running `php artisan serve`)
- API prefix: `/api`
- Example endpoint: `GET /api/jobpost/allposts`

## Common Commands

- `php artisan serve` – start the local development server.
- `php artisan migrate` – run database migrations.
- `php artisan route:list` – list all available routes.
- `php artisan config:clear` – clear configuration cache.
